## Sobre mí

Soy desarrollador backend enfocado principalmente en **Java**, **Spring Framework** y **SQL**, además de usar **Python** para automatización y manejo de datos. Me gusta involucrarme desde el análisis de requerimientos para entender bien el problema antes de tirar código, buscando siempre que los servicios queden modulares, seguros y bien probados.

## ¿Qué hay en este proyecto?

Quise darle un diseño diferente al típico CV plano, usando un estilo **Neo-Brutalista en formato Bento Grid**, pero manteniendo todo ligero en HTML y CSS puro para que cargue rápido y sea fácil de actualizar desde cualquier lugar.
